About me

I'm a GIS professional with experience designing and managing enterprise geodatabases, running geospatial analysis, and building maps and applications that support environmental and conservation planning. My background spans conservation, land management, urban development, and public-sector mapping.

As a GIS Data Analyst at the Great Lakes Commission, I manage geospatial data and build GIS products for environmental planning across the Great Lakes region. That work includes designing geodatabases, building internal and public-facing apps in ArcGIS Experience Builder, publishing and maintaining web services in ArcGIS Online and Enterprise, and producing standardized map and data products for the EPA Inland Sensitivity Atlas, which federal and state partners use for environmental emergency response planning.

Before joining the GLC, I administered enterprise GIS databases (ArcGIS Pro, SQL Server) at Bedrock Real Estate in Detroit, where I also built a workflow to turn CAD files into 3D building models. For my master's capstone at the University of Michigan, I was the GIS specialist on a team working with the National Park Service to design a conceptual trail network through a sensitive Lake Michigan dune landscape near South Haven.

Agriculture in the Great Lakes

Type
Dashboard · analysis
Built with
Microsoft Power BI
Features
Clip-to-basin toggle, source notes on every visual

In 2024 the Great Lakes Commission adopted a policy resolution on agriculture and water use under changing climate conditions. With support from The Joyce Foundation, GLC staff worked with experts across the region on three questions: what agricultural production in the basin looks like today, what might be grown under future climate conditions, and how agricultural water use could change.

This dashboard is the product of the first phase. It lets users explore baseline conditions for crops, livestock, land cover, water use, and climate across the basin, along with recent patterns of change. It was built as a companion to the GLC report Impacts on Great Lakes agriculture and water use under changing climate conditions. The next phase of the project looks ahead to mid-century, focusing on the most water-intensive crops and how irrigation demand may shift.

Habitat Restoration in Great Lakes Areas of Concern

Type

Built with

Program
NOAA–GLC Regional Habitat Restoration Partnership

Areas of Concern (AOCs) are Great Lakes watersheds with degraded environmental conditions from historic and ongoing pollution, designated under the U.S.–Canada Great Lakes Water Quality Agreement. Since 2008, the Great Lakes Commission and NOAA have partnered to design, build, and monitor high-priority habitat restoration projects in these AOCs, with funding from the Great Lakes Restoration Initiative. As of 2024, the partnerships total more than $70 million, covering 45 multi-phase projects in eight AOCs.

I created this ArcGIS StoryMaps collection to share the partnership's work with the public. It contains three story maps, for the Maumee River, Niagara River, and Muskegon Lake AOCs, each presenting project details and highlights. A locator map ties them together so readers can move between sites across the basin.

Databases & data structures

A statewide point layer built to the EPA Region 5 Inland Sensitivity Atlas (ISA) data standard, used by federal and state partners for environmental emergency response planning.

Boating Access Sites · Michigan

Type
Point feature class · ISA standard schema
Records
2,988 sites · 19 attribute fields
Verified
June 15, 2026 (VERIF_DATE)
Built with
ArcGIS Pro, Python, BAC Web Scraper

The Inland Sensitivity Atlas is a series of GIS map products developed by U.S. EPA Region 5 to support hazardous materials spill contingency planning and response under the Oil Pollution Act of 1990. The atlases document environmentally sensitive resources, sensitive human-use resources, potential spill sources, and response features. The Great Lakes Commission maintains the data for Michigan, Ohio, and Indiana, updating one state at a time.

The boat access layer maps concrete, asphalt, gravel, and earthen ramps, which can give responders important access to the water during a spill. Ramp locations appear on the atlas PDF maps, and the full records live in the GIS database.

For each layer I update, including this one, I follow the ISA Reference Manual. I compare the existing atlas data record by record against current sources, add new sources where they fill gaps (for boat access, the BAC Web Scraper), and format every record to the ISA data entry standards: no field left blank, N/A where information is unavailable, and consistent naming and phone formats. Each feature gets a 1–5 accuracy rating and a verification date. Before delivery, internal QA/QC confirms the data structure and field names, that every feature has a complete attribute record, attribute accuracy and spelling, positional accuracy (within ±820 ft at minimum, with ±82 ft as the goal), and current metadata. A partner organization or EPA subcontractor then performs an external QA/QC review.

Boating Access Locations (BAC) Web Scraper

Type
Data acquisition · Python script
Built with
Python, Selenium, BeautifulSoup, pandas
Output
Boat_Launches.csv: Michigan boat launch names, owners, latitude/longitude, site attributes

I developed a Python web scraper using Selenium, BeautifulSoup, and pandas to automate the collection of boating access location data from Outdoor Michigan. The script navigates through paginated listings, identifies individual boat launch pages, and extracts relevant attributes, including launch names, managing townships, geographic coordinates, launch types, and other site characteristics. The collected data is organized into a structured table and exported to CSV for GIS processing.

Within the EPA Region 5 Inland Sensitivity Atlas (ISA), this tool helped address a data gap in boating access locations by automating data collection that would otherwise require extensive manual research. The resulting dataset supports GIS data development, validation, and integration into the ISA, improving the availability of boating access information for emergency response planning.

Automation & data workflows

Python notebooks that move field submissions into hosted feature layers and keep records consistent.

Survey123 Excel Append

Type
Workflow automation · ArcGIS Notebook
Built with
ArcGIS API for Python, pandas, Survey123
Supports
Mussel Control Mapping Tool, spreadsheet upload

I developed an ArcGIS Notebook using Python, the ArcGIS API for Python, and pandas to automate the integration of field data submitted through Survey123 and Excel spreadsheets into the Mussel Control Mapping Tool’s hosted GIS layers. The workflow was created to reduce manual data entry, keep equipment locations and status information up to date, and maintain consistent records for the Invasive Mussel Collaborative’s control efforts.

The notebook validates and processes incoming records, adds new equipment locations, updates existing records, and tracks processed submissions using an OBJECTID log to prevent duplicate entries. Scheduled to run approximately every 15 minutes, it helps keep the interactive Experience Builder map current and supports coordination of invasive mussel control equipment across the Great Lakes.

Mussel Control Mapping Tool – Unique ID Generator Notebook

Type
Data structure / QA workflow · ArcGIS Notebook
Built with
ArcGIS API for Python
Supports
Mussel Control Mapping Tool, three Survey123 feature layers

I developed a Python ArcGIS Notebook to generate and manage unique identifiers for equipment tracked in the Mussel Control Mapping Tool. The notebook helped establish a consistent identification system so each piece of control equipment could be distinguished and located within the shared GIS database.

These unique IDs were incorporated into the ArcGIS Experience Builder mapping tool, allowing field teams to search for a specific piece of equipment by its ID while working in the field. This made it easier to find equipment locations, verify placement information, and coordinate equipment tracking across the Great Lakes. The tool supported the Invasive Mussel Collaborative’s efforts to manage invasive mussel control equipment and protect critically endangered whitefish spawning reefs.
